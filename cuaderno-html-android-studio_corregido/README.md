# Cuaderno HTML — Wrapper APK Android

Convierte tu archivo **Mis Web APIs.html** en una aplicación Android nativa con tu logotipo PNG, almacenamiento persistente **IndexedDB**, selector nativo de archivos `.html` (`onShowFileChooser`), soporte para diálogos `prompt()`/`confirm()` y navegación con el botón Atrás.

## Cómo generar tu archivo .apk
1. Sube esta carpeta (incluida la carpeta `.github`) a un repositorio en **GitHub**.
2. Entra a **Actions → Compilar APK Android** y ejecútalo.
3. Descarga el artefacto **`app-debug.apk`** resultante en ~2 minutos.
*(O abre esta carpeta en **Android Studio → Build → Build APK(s)**).*
